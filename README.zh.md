# 图片右键菜单

[English](README.md) · 独立社区插件 · MIT

为 **Codex 生成的图片**添加五项操作：

1. 在新标签页中打开图像。
2. 添加原图到聊天输入框，**不改写已有文字，不自动发送**。
3. 复制原始 PNG 图像。
4. 在资源管理器／Finder 中显示原图文件（需要有效的本地路径提示）。
5. 下载保留原始字节的副本。

独立安装，不覆盖 `dsh-codex-subscription` 文件；通过 Harness Slots 包装原有图片组件，保留其点击预览、编辑、标注和图库操作。不读取 React 私有数据，不替换应用根节点，不增加模型工具。

## 兼容范围与限制

已针对 **DeepSeek Harness 0.2.2-rc.1** 与 **dsh-codex-subscription 3.2.6、3.2.7** 验证。安装清单声明的是兼容范围而非单一版本：`engines.dsh` 为 `>=0.2.2-rc.1 <0.2.3-0`，上游 peer 为 `>=3.2.6 <3.3.0`。适配依赖该版本的图片元数据、组件席位及查看器结构，并非上游正式承诺的稳定图片扩展 API。上游小版本（3.3.x）或宿主小版本（0.2.3）变化时需要重新做适配测试才能放宽范围；不要为了安装而绕过版本检查。

- 支持生成图片卡片，以及 Codex 的**增强图片查看器**；不是全局拦截任意图片。
- 关闭增强查看器后，卡片菜单仍可用，但替代的原生查看器不在本适配范围内。
- 浏览器版会打开原图浏览器标签页，可能需要允许弹出窗口。
- 桌面版受 Electron 限制，改为打开 **Harness 内的独立图片标签页**。
- 缺少或无效的路径提示会禁用“在资源管理器中打开”；远程连接时，文件位置是在提供服务的主机上显示。
- 原图丢失、来源无法唯一匹配、组件结构不支持或校验失败时，不会偷偷用缩略图代替原图。

## 安装与迁移

先安装并启用上述兼容版本的 Codex 订阅插件，再从本仓库 **Releases** 下载 `.tgz`，通过 Harness 的插件安装流程添加，或执行：

```sh
dsh plugin add ./dsh-image-context-menu-0.1.1.tgz
```

桌面前端有缓存时，请完全退出应用（包括托盘）后重新打开。安装包附带构建产物，不执行安装期脚本，不需要在用户电脑上构建。

如果之前使用的是手工修改过的 Codex 图片插件，请先保留备份，再通过正常插件管理流程重装同版本上游，最后安装本独立插件；本插件不会擅自恢复、修改或删除原插件文件。迁移验收后再清理旧备份。

禁用／卸载时会释放菜单、监听器、快捷键保护、Blob URL 和 Slot 包装，让原有组件恢复呈现。

## 隐私与安全

只在用户执行图片操作或加载原图标签页时，通过现有会话授权的 Codex 分块接口读取原图；逐块验证元数据、偏移、字节数和规范 Base64，最后验证 SHA-256。会话及继承图片的权限仍由上游主机检查。

不含遥测、分析上报、额外服务器、磁盘扫描、凭据读取或自动发送行为。复制、保存和显示位置复用 Harness 原有服务。显示位置只使用上游结果中已有且通过严格验证的路径，不猜测用户目录；这个路径提示并非签名或稳定的结构化接口，因此是可选能力。

## 开发与验证

开发和发行检查使用 Node 24；构建、测试没有第三方开发依赖：

```sh
node scripts/build.mjs
node --test --test-isolation=none test/*.test.mjs
node scripts/check-package.mjs
npm pack --ignore-scripts --pack-destination dist
```

测试覆盖原图读取、Slot 适配和生命周期的隔离逻辑，**不等同于浏览器或跨平台端到端验证**。扩展兼容范围前，需要在目标版本实际验收剪贴板、下载／文件定位、图库切换、菜单键盘操作和禁用后恢复。
